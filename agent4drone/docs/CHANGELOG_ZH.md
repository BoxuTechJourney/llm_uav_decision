# 变更日志

本项目的所有重要变更均应记录在此文件中。

## [0.4.0] - 2026-06-06

### 新增
- 新增 `--ui-drone-control` 以启用UI无人机控制，包括起飞/降落按钮和地图点击移动命令。
- 新增 `GET /sessions/current/command-history` 作为一个便捷端点，用于获取当前会话的近期命令历史。
- 新增仅运行时的HTTP请求历史，提供当前会话和显式会话查询端点、敏感值遮蔽以及客户端/身份验证审计上下文。
- 新增使用非机密 `X-Agent-ID` 归属头的AGENT角色对 `GET /sessions/current/request-history` 的筛选访问。
- 新增SYSTEM/ADMIN角色的 `DELETE /sessions/current/request-history` 和 `DELETE /sessions/{id}/request-history` 端点，用于清除运行时请求历史而不重置会话。
- 新增 `--request-history-limit` 启动配置，并将每个会话的默认请求历史保留记录数增加到5000条，同时API响应上限保持在1000条。

### 修复
- 通过避免捕获完整响应体并仅对每个请求历史响应所需的记录进行规范化，改善了请求历史的响应时间。
- 保留了可回放的请求历史查询参数，包括有序重复键、敏感值遮蔽、失败请求和旧的 `{}` 默认值。
- 将请求历史排除在序列化会话对象、JSON导出、导入和恢复之外，使其保持为进程本地的运行时状态。
- 将请求历史的 `client_privilege` 值标准化为大写角色名称。

## [0.3.9] - 2026-05-23

### 修复
- 在当前会话重新加载并重新创建无人机特定路径设置时，保持UI路径轨迹长度按钮选择不变。

## [0.3.8] - 2026-05-10

### 变更
- 为 `move_along_path` 添加了成功和失败航点计数以及 `(x, y, z)` 坐标三元组的简单响应字段。
- 将 `move_along_path` 的点反馈字段移到了专用的响应模型中，这样其他命令模式就不会显示路径专用字段。
- 保持 `move_along_path` 的错误响应专注于错误消息，而不包含点反馈值。
- 更新 `move_along_path` 的局部移动响应，当 `allow_partial_move=true` 至少到达一个航点但在到达请求的终点前停止时，返回 `partial_success`。

## [0.3.6] - 2026-05-03

### 变更
- 更新 `move_along_path`，通过将省略的 `z` 值默认为调用无人机的当前高度，来接受二维 `{x, y}` 航点。
- 更新 `move_along_path` 的局部移动，当 `allow_partial_move=true` 时，会在电量充足的最后航点处停止，而不是在全路线超出可用电量时拒绝整个路径。
- 更新 `move_along_path` 的电量消耗，移除每个航点的基本成本，使路径跟随仅按水平和垂直距离计费。
- 通过批量处理内部覆盖跟踪、重用路径计算以及避免在命令记录期间序列化完整会话历史，优化了 `move_along_path` 对于大型航点列表的响应时间。
- 更新 `move_to` 的电量消耗，移除基本移动成本，与仅按距离计费的移动方式保持一致。
- 更新启动时的用户界面提示，使其使用与主图形仪表板相同的无人机窗口图标。
- 更新目标和障碍物画布标签，以在每个对象的类型下方显示其ID。

## [0.3.4] - 2026-04-25

### 新增
- 添加了多个硬编码的 USER、SYSTEM 和 ADMIN 权限密钥用于 API 认证，同时保留现有的 AGENT 认证行为。
- 为任务检查端点添加了可选的 `since_timestamp` 范围限定，以便兼容的历史检查可以验证在给定时间戳或之后执行的工作。

### 变更
- 更新了认证文档和示例，使用 API 密钥占位符，而不是发布具体的密钥值。
- 更新了目标到达和移动目标跟踪检查端点，以支持 `since_timestamp` 过滤。
- 更正了降落历史检查文档，以描述已实现的 `min_count` 参数。
- 更新了 PyInstaller 打包，将项目子模块作为隐藏导入包含在内，以便冻结的 Windows 构建版本可以导入本地模块，例如 `config.battery_config`。

## [0.3.3] - 2026-04-22

### 变更
- 扩展了 ADMIN 历史检查端点 `GET /check/drone_has_taken_off`，以支持可选的 `max_altitude` 和 `tolerance` 查询参数，从而通过 `min_altitude == max_altitude` 实现向后兼容的最小阈值检查、有界高度范围检查和精确高度检查。
- 更新了起飞历史检查响应和文档，以包含应用的高度界限和容差元数据。

## [0.3.2] - 2026-04-08

### 新增
- 新增对会话截图的 SVG 和 EPS 导出支持。
- 新增 `show_status` 截图选项，包含路径轨迹、区域覆盖、到达/跟踪的目标状态和 UI 风格的状态栏详细信息。
- 新增 ADMIN 检查端点 `GET /check/drone_group_distance`，用于验证一组无人机之间的成对距离约束，具有 `all_pairs` 和 `any_pair` 模式。
- 新增 ADMIN 检查端点 `GET /check/drone_has_sent_message_content`，用于验证无人机是否发送了包含所请求子字符串的消息文本，包括广播消息。

### 变更
- 重构了截图渲染，以使用共享的场景模型进行栅格和矢量导出。
- 更新了截图 API 文档，以涵盖新格式和 `show_status` 查询参数。
- 更新 PyInstaller 打包，使用紧凑的可执行文件版本格式，因此应用程序版本 `0.3.2` 构建为 `MultiUAV-Plat.Server.v0.32`。
- 更新 API 参考、API 文档和认证文档，描述新的无人机群距离检查及重复查询 `drone_ids` 的用法。
- 更新消息检查文档，描述新的内容匹配端点及其包含广播的行为。
- 更新 `move_along_path`，默认接受 `allow_partial_move=false`，并提供可选的局部完成，即停在障碍物前的最后一个安全航点，并在成功消息中报告提前停止。
- 更新 `move_along_path` 以接受单个航点，因此单点路径请求将作为有效路径移动处理，而不会被拒绝。

## [0.3.1] - 2026-04-06

### 新增
- 添加了跨平台 PyInstaller 规格文件 `multiuav_plat.spec`，用于在 Windows、macOS 和 Linux 上进行可重现的独立构建。
- 添加了原生 PyInstaller 图标资源，位于 `ui/img/drone.ico` 和 `ui/img/drone.icns`，由现有项目图标生成。

### 更改
- 从后端会话模型、会话 API、示例会话有效负载和 API 文档中移除了会话 `time_mode` 属性。
- 更新了 `README.md` 中的独立部署文档，使用共享的规格文件而非特定于平台的内联 PyInstaller 命令。
- 将编译后二进制文件的文档化 UI 启动标志更正为 `--ui`。
- 更新 PyInstaller 规格文件，在 Windows 和 macOS 上自动设置可执行文件图标。
- 在服务器合约、测试、README 和 API 文档中，将标准和障碍物 API 有效负载统一为规范的 `type` 字段，替代旧的 `target_type` 和 `obstacle_type` 名称。
- 在 UI 中添加工具栏切换按钮，用于显示或隐藏无人机、目标和障碍物的画布标签。

## [0.3.0] - 2026-04-01

### 新增
- 为目标响应添加了显式的移动目标运行时字段：
- `movement_mode`
- `last_motion_update`
- `tracking_status`
- `last_tracked_at`
- 通过 `moving_target_tracking` 在会话历史中添加了后端拥有的移动目标跟踪状态。
- 添加了 ADMIN 检查端点 `/check/moving_target_tracked`，用于验证任何无人机或特定无人机的移动目标跟踪持续时长。
- 添加了针对移动目标创建、验证、运动步进和跟踪行为的专用回归测试。
- 在 `docs/CHANGELOG_ZH.md` 中添加了初始项目变更日志。

### 更改
- 重构了移动目标处理，使活动目标对象成为运动状态的权威运行时来源。
- 重构了会话同步，使用显式的快照同步 API，而不是在会话读取时发生变更。
- 更新了移动目标运动处理，使用显式的内部运动模式：
- `velocity`
- `path`
- `stationary`
- 更新了基于路径的运动，以在更大的时间步长中确定性推进。
- 更新了移动目标的碰撞行为，采用特定于模式的反向逻辑。
- 更新了 `target_tracking` 任务进度，移动目标使用基于后端新鲜度的跟踪语义，而不是 UI 本地超时逻辑。
- 丰富了 `moving_target_tracking`，添加紧凑的每无人机最近时间段，使得特定无人机持续时长检查成为可能，而无需存储无界的原始事件日志。
- 更新了目标检索路径和 UI 渲染，以消费规范的后端跟踪和移动状态。
- 更新了 API 文档和参考文档，描述新的移动目标运行时字段和会话跟踪有效负载。

### 修复
- 修复了由于会话快照滞后于实时模拟状态而导致的移动目标状态陈旧问题。
- 修复了后端和 UI 层中重复的运动模式推断问题。
- 修复了由无人机目标到达循环触发的重复会话写入/快照副作用。
- 修复了路径验证缺陷，拒绝退化的移动路径和与障碍物冲突的路径段。
- 修复了历史目标到达与当前移动目标跟踪显示之间的不一致问题。

### 兼容性
- 现有的目标请求有效负载仍然受支持。
- 旧版目标响应字段，如 `is_reached` 和 `reached_by` 仍可用于兼容性，但移动目标的新鲜度现在源自后端跟踪状态。
