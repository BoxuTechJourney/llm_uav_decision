# MultiUAV-Plat Web 3D 查看器

语言：[English](README.md) | **中文**

这是一个独立的、基于 Three.js 的 MultiUAV-Plat 只读可视化查看器。

当前前端被设计为最终的可视化呈现界面，重点展示实时任务状态，并从用户可见的操作流程中移除了无人机控制、场景编辑以及修改后端数据的工具。

## 功能

- 默认通过 `npm run dev` 以“后端优先”模式启动。
- 读取后端当前会话，并将其渲染为三维场景。
- 后端不可用时，自动回退到本地演示任务。
- 显示无人机、目标、障碍物、高度线、历史轨迹和覆盖区域。
- 支持以只读方式选择对象并通过信息抽屉查看详情，包括对象 ID/名称、多边形原始顶点，以及后端提供的投影面积（如果存在）。
- 提供多种相机控制：适应全部对象、俯视、跟随选定无人机，以及沿选定无人机的轨迹漫游。
- 提供小地图、场景统计、状态摘要、标签开关、标签大小控制、轨迹模式、连续覆盖表面、快速缩放比例和浏览器端截图导出。
- 默认使用英文界面。
- 最终可视化 UI 不会发送无人机命令，也不会编辑后端场景数据。

## 环境要求

- Node.js 18 或更高版本。
- 如需实时数据，可选启动运行在 `http://127.0.0.1:8000` 的 `server` FastAPI 后端。

## 安装

```bash
cd view3d
npm install
```

## 运行

如需显示实时会话数据，请先在仓库根目录启动后端：

```bash
cd server
python main.py --api-only --host 127.0.0.1 --port 8000
```

然后从仓库根目录启动 3D 查看器：

```bash
cd view3d
npm run dev
```

打开：

```text
http://127.0.0.1:5173
```

`npm run dev` 会启用后端数据模式并运行 Vite：

```bash
VITE_VIEWER_DATA_SOURCE=backend vite --host 127.0.0.1 --port 5173
```

如果后端不可用，或 `GET /sessions/current/data` 请求失败，查看器会自动切换到本地演示任务，确保页面仍然可以正常渲染。

如需明确使用纯前端演示模式，请运行：

```bash
npm run dev:demo
```

## 配置

如果后端没有使用默认地址，或者后端要求 API 密钥，请将 `.env.example` 复制为 `view3d/.env.development.local`：

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_API_KEY=
```

当 `VITE_API_KEY` 为空时，请求会使用后端默认的 AGENT 角色行为。查看器必须有权读取以下接口，才能显示后端实时数据：

```text
GET /sessions/current/data
```

## 后端数据契约

最终可视化 UI 只需要当前会话数据接口即可进行实时渲染：

- `GET /sessions/current/data`

前端截图功能完全在浏览器端实现，不需要后端截图接口。

## 操作方式

- 鼠标左键：选择无人机、目标或障碍物，进行只读检查。
- 鼠标右键：清除当前选择。
- 鼠标拖动/滚轮：旋转视角，并在 40%～500% 的比例范围内缩放相机。
- 相机按钮：在适应全部、俯视、追踪跟随和轨迹漫游视角之间切换。
- 信息按钮：打开当前选中对象的只读详情抽屉。
- 单击小地图：将视图中心移动到所选位置。
- 标签开关：显示或隐藏对象标签。标签初始大小为 100%；只有标签可见时，`Size-` / `Size+`、`[` / `]` 和双击重置才会生效。
- 轨迹模式：切换历史轨迹的显示范围。
- 默认将覆盖区域显示为连续表面。
- 快速缩放：使用右侧垂直滑块、鼠标滚轮或 `+` / `-`；双击右下角的比例文字可重置为 100%。该比例也会影响 Follow 和 Roam 模式下追踪相机的距离。
- 截图：从浏览器导出当前画布图像。

键盘快捷键：

- `Esc`：清除选择。
- 方向键：平移视图。
- `1`：适应全部对象。
- `2`：切换到俯视图。
- `3`：从抬高的后方追踪视角跟随选定无人机。
- `4`：从抬高的后方追踪视角沿选定无人机的完整轨迹漫游。
- `.` / `,`：加快/减慢当前轨迹漫游的播放速度。
- `+` / `-`：放大/缩小。
- `[` / `]`：标签可见时减小/增大标签尺寸。
- `R`：重置视图。
- `L`：显示/隐藏标签。
- `M`：显示/隐藏小地图。
- `I`：显示/隐藏信息面板。

最终可视化 UI 不会向无人机发送任何命令。
